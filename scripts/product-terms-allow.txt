# Allowlist of scripts/check-product-terms.sh.
#
# Format, one entry per line:
#
#   <path>|<term>|<fixed substring of the offending line>|<reason>
#
# A hit is suppressed when its path and term match and its line contains the substring. A
# substring of `*` covers every line of that path and term; use it only where a whole file
# uses the word in one generic sense. The reason is mandatory. An entry that suppresses
# nothing is stale and fails the gate: delete it. No field may contain `|`.
#
# Review rule: each entry is a legitimate generic use (networking, OS or measurement
# vocabulary). Product uses are reworded, not allowlisted.
