## Description

The owner asked for DNS policy control in `nsplane-dns`: which names or record types are
answered locally and which are forwarded, so that downstream clients can build specific
features on it; CNAME rewriting is included. Today only `Fallback` (on `NXDOMAIN`) and
`FakePool::with_fallback` compose resolvers.
