# ADR: Quality gates run locally, not in CI

Status   : Accepted
Date     : 2026-10-01
Sunset   : 2027-04-01 (reassess once the fork has more than one regular contributor)

## Context

pma-rust Lock 8 expects the quality gates to run in CI. The project owner decided to remove
the upstream GitHub Actions workflows from the fork.

## Decision

- The gates are encoded in the `justfile`: `just check` runs fmt, clippy for every feature
  (`cargo hack --each-feature`), nextest, doctests, cargo-deny, cargo-shear, typos and the
  MSRV check. `just cross` adds macOS (zig) and Windows (mingw-w64 + nasm) clippy runs.
- The policy (deny warnings, lint levels) lives in `[workspace.lints]`, so local runs and any
  future CI see the same gate.
- Every change is pushed only after `just check` passes.

## Consequences

Nothing enforces the gate on push; it relies on discipline. Re-adding a CI workflow that runs
`just check` is a one-file change.
