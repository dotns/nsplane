## Context

See the task. Every `ArcSwap` in nsplane sits on a per-packet read path:
- `nsplane-acl`: the engine's rule set, the filter scope set (added by GF-4 in campaign
  `nsplane-gf-202610121800`) and the gate snapshot;
- `nsplane-nat`: translate and `nat64_lan`. `Nat64Lan::new` exposes `ArcSwap` publicly.

## Work (one L2, after the GF L2 has merged into main for the nsplane-acl part)

1. Design note to L1 (yellow gate). It covers:
   - where the cell lives (one private copy per crate, or a small public module in a crate both
     already depend on, e.g. `nsplane-core` or `nsplane-packet`);
   - its read design and read cost, with options:
     - sharded `RwLock` as ns does;
     - a generation counter plus a reader-held cached `Arc`, for readers that own state per
       worker or per filter clone;
     - other std-only designs;
   - why the chosen design is sound (no unsafe outside nsplane-tun and nsplane-noise);
   - the AS-2 public handle for `Nat64Lan` (e.g. a `LanRoutes` handle with `replace` / `load`);
   - the bench plan.
2. `nsplane-nat` (AS-1 and AS-2). This can start at once.
3. `nsplane-acl` engine, filter scopes and gate (AS-1). This starts after `git merge main` once
   GF is in main.
4. Remove `arc-swap` from every Cargo.toml and from Cargo.lock. Add a multi-instance concurrency
   test (replace under load, no wrong-instance read). Update the e2e `nat64_lan` test, the
   CHANGELOG (Fixed, Changed), architecture and a consumer note.
