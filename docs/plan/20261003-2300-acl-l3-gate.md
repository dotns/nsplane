## Context

ns account mode still filters with its own `AccountFilter`
(`/srv/dotns/ns/crates/ns/src/account_engine/filters.rs` on `refactor/nsplane`), which calls
`tunnel_wg::acl_check_packet` (`crates/tunnel-wg/src/tun_io.rs`: `crates/acl` with the
packet's source address as principal, relay client keys judged by WireGuard key,
`FragmentAclGate`), the node L3 gate (`crates/tunnel-wg/src/node_l3*`, about 3.2k lines plus
2.3k lines of tests) and the dynamic L3 route checks. Owner rule and ADR
`2026-10-03-data-channel-protocols-in-nsplane`: per-packet code belongs in nsplane; ns keeps
policy compilation and projection (it still builds `NodeL3Config` and the ACL policy from its
control messages). Assessment: MD-1, 4, 5, 6 small to medium; MD-2 large; MD-3 lands with
MD-2.

Conventions: additive APIs, defaults keep today's behavior, nothing costs anything when not
installed, every item has unit tests and an `nsplane-e2e` test, ns's own tests are ported
for every ported behavior (they are the semantic reference; the ns code may be read and
ported, never modified).

## Contract

### MD-A: ACL parity (`crates/nsplane-acl/**`, `crates/nsplane-core/**` for MD-6)

- MD-1 per-packet source principal: `PeerIdentity::assertion_for(&self, peer, src: IpAddr)
  -> Option<SourceAssertion>` with a default that delegates to today's per-peer assertion;
  `PeerIdentityMap` can mark a peer "terminate by source address" (principal
  `Terminate { ip: Some(src), anchor: src.to_string() }`, as `AccessRequest::from_ip`) and
  keeps `WgPeerKey` for relay client keys (`with_wg_peer_key`). The principal cache, the flow
  verdict cache and the per-peer bypass stay correct (cache per (peer, src) under the
  identity generation; a by-source peer is never bypassed unless its policy is allow-all for
  every source).
- MD-4 fragment parity with ns `FragmentAclGate`: non-first IPv4 fragments are judged by the
  remembered verdict of their datagram's first fragment keyed (src, dst, proto, id), with
  ns's TTL and capacity; a miss drops. Keep or replace today's gate so that one mode equals
  ns exactly (selected by `AclFilterConfig`), tests ported from ns `primitives/tests.rs`.
- MD-5 bypass flags in `AclFilterConfig` (default off): `accept_to_local: Option<Ipv4Addr>`
  (ns `is_local_node_packet`), `accept_icmp_echo_reply: bool` (ns `is_icmp_echo_reply`);
  `stateful_replies: false` must equal `crates/acl` exactly (no reply allowances, no flow
  verdict side effects): a parity test suite runs ns's `acl_check_packet` cases (ported) and
  a generated set of five-tuples against both the ported expectations and nsplane-acl.
- MD-6 destination authorization: `PeerConfig::inbound_destinations: Option<Vec<AllowedIp>>`
  (`None` = unchecked, today's behavior), checked by the core after decryption next to the
  source check, dropped as a new `reasons::DESTINATION_NOT_ALLOWED`; runtime update through
  `ConfigChange` like allowed IPs. The outbound "route owner mismatch" check is covered by
  routing when ns expresses leases as allowed IPs; document the mapping for ns
  (`DynamicL3RouteTable` leases and Subnet returns -> allowed IPs / inbound destinations).

### MD-B: node L3 gate (`crates/nsplane-acl/src/l3*` or a new module; e2e)

- Design note to L1 before coding (yellow gate): the nsplane-side configuration model
  mirroring ns `control::messages::NodeL3Config` (nsplane cannot depend on ns `control`; ns
  converts), the gate's state and locking (the stateful flow table must stay off a global lock
  on the hot path, like the ACL hook), and the composition with `AclFilter` where an enforced
  allow ends evaluation before the L4 ACL (one ordered filter, since `Verdict` has no
  final-accept; Legacy and Observe fall through to the ACL).
- MD-2 port of the gate's semantics: target-bound Node / Service / Subnet grants, source
  binding, the same-owner rule, the stateful flow table with per-protocol idle timeouts (TCP
  2 h, half-close 5 min, terminal 30 s, UDP 2 min, ICMP 30 s, other 60 s), per-peer (2,048)
  and global (16,384) limits with a StateCapacity drop, orphan-fragment drop, ICMP errors
  matched to their flow, modes Legacy / Observe / Enforce, the Subnet LAN DNS transport
  admission, reasons mapped 1:1 to `NodeL3Reason`, observe counters.
- MD-3 divert: a SourceBinding / OrphanFragment denial with a gateway-consumer candidate is
  `try_send` to a caller channel and reported as `Verdict::Handled` (ns `gateway_consumer`).
- Tests: every ns `node_l3/tests/*` case ported; e2e through two engines (grants, state,
  limits, modes, divert); a bench for established flows and new flows (target: an established
  flow within the ACL hook's cost class, bypass when the gate is not installed = zero cost).
