Notes on the contract:
- MQ-1 is the largest item: a per-path (or per-transport) MTU ceiling in the engine and PMTU
  handling of the outer path (ICMP Packet Too Big / Fragmentation Needed for the encrypted
  datagrams), so the inner MTU the local side sees (MTU watch, fragmentation stage) follows
  the peer's current path. RX sends L1 a design note before coding it.
- MQ-3: an outbound source constraint per filter (allowed source prefixes), checked before
  the destination rules, default off; MQ-7: rules for ICMP/ICMPv6 (at least Echo) and other
  protocols scoped to destinations, without `allow_other_protocols`' blanket accept.
- MQ-9 is a new mapping in the translator (`alias6(b)` IPv4 address <-> peer b's native IPv6
  `N6(b)`), distinct from today's `PeerMapping.alias6`.

Shared files: `CHANGELOG.md`, `docs/architecture.md`, new e2e test files, the task doc,
`Cargo.lock`. L1 merges by completion.
